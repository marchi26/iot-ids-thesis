# ESP32 Wokwi IDS Demo

This directory contains a Wokwi/PlatformIO demonstration for the thesis IDS project.

The simulated ESP32 runs a compact binary Logistic Regression model exported from the real TON_IoT dataset. The model uses a small numeric feature subset and quantized `int16` coefficients generated by:

```powershell
python src/experiments/export_embedded_model.py
```

Generated files:

- `include/embedded_model.h`: auto-generated model coefficients, scaler values, test samples, and reference metrics;
- `src/main.cpp`: Arduino firmware that performs local inference on the ESP32;
- `diagram.json`: Wokwi circuit with one red attack LED and one green normal LED;
- `wokwi.toml`: Wokwi CLI configuration for the compiled PlatformIO firmware.

## Run Locally with PlatformIO

From this directory:

```powershell
pio run
```

Then start the Wokwi simulation with the VS Code Wokwi extension or Wokwi CLI:

```powershell
wokwi-cli .
```

The Wokwi CLI requires a local `WOKWI_CLI_TOKEN`. Do not commit tokens or credentials.

## Interpretation

This demo does not reproduce the full LightGBM baseline on ESP32. It is a deployment-oriented demonstrator that shows how a smaller IDS model can be exported, quantized, embedded in firmware, and executed on simulated IoT hardware.
